# Lab7 — Makefile, статична та динамічна бібліотеки на C

Мета лабораторної роботи — навчитись збирати проєкт на C за допомогою `Makefile` і зрозуміти різницю між **статичною** та **динамічною** бібліотекою.

Функція `f(x) = sin(x) + cos(x)` винесена в окрему бібліотеку `libfunc`. Головна програма (`Lab7.c`) читає параметри з `input.txt`, будує таблицю значень `f(x)`, записує її в `output.txt` та `data.bin`, зчитує `data.bin` назад і виводить таблицю на екран. Репозиторій містить два варіанти однієї програми, які відрізняються лише тим, як підключається бібліотека.

| | `Lab7/` | `Lab7_dynamic/` |
|---|---|---|
| Тип бібліотеки | статична | динамічна |
| Файл бібліотеки | `libfunc.a` | `libfunc.so` |
| Програма | `lab7_static` | `lab7_dynamic` |
| Код бібліотеки потрапляє | всередину програми при збірці | не потрапляє, підвантажується при запуску |
| Чи потрібна бібліотека для запуску | ні | так (`libfunc.so` має лежати поруч) |
